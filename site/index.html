Production-grade multi-agent workflow scaffold. Built from the Microsoft Gold-Path — dependency-free agent core, MCP-compatible tools, one-command azd up deploy.

View on GitHub

What it is

Agent Core

Bounded orchestration chaining — no infinite tool loops. Agent + Tool + LLMClient abstractions.

MCP Tools

Cost lookup, remediation script generation. Guardrail: write, never delete.

Orchestrator

Sequential multi-agent pipeline with pluggable checkpointing (durable-task pattern).

Observability

OpenTelemetry + Azure Monitor (App Insights) on by default.

Cloud LLM

Azure OpenAI + Foundry Agent Service, env-selected. No secrets in code.

IaC + Deploy

Bicep + azd up: RG → Log Analytics + App Insights → Container App + Managed Identity.

Architecture

User → Container App (svc :8000) → Managed Identity → Agent loop → Tools (MCP-style) | Azure OpenAI / Foundry → OpenTelemetry → Application Insights (IaC: Bicep provisioned via azd)
